家庭保单检视
上传已有保单材料，生成家庭保单检视报告
检视所需材料清单
按以下三类整理材料上传，系统会自动解析保单信息并生成检视 PPT。
* 标记为必填项，财务概览截图建议全部上传以获得最准确的检视结果。
1. 保单详情页 HTML / PDF / 图片 · 必填
每个保单从保诚系统查到的「保单详情」页，另存为HTML上传。
HTML 会自动解析基本信息做汇总表；如果只有截图也可以传，走OCR识别。
拖拽保单详情页 HTML / PDF / 截图到这里
或点击选择文件（支持批量上传，HTML / PDF / PNG / JPG）
2. 提取方案计划书 PDF / HTML / 图片 · 储蓄险专用
储蓄分红险（隽富EGC、世誉PRMESP等）的不同提取方案页面。
每个提取方案一份，直接收集贴入PPT，用于制作提取详情页。
拖拽提取方案页面 PDF / HTML / 截图到这里
或点击选择文件（支持批量上传，PDF / HTML / PNG / JPG）
3. 当前财务概览截图 图片 · 建议全传
每个保单的「当前财务概览」截图（如 2026年10月），包含当前现金价值、累计已交保费等实际数据。
用于制作检视时点的财务概览页。
拖拽财务概览截图或PDF到这里
或点击选择文件（支持批量上传，PNG / JPG / PDF）
